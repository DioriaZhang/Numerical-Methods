## 前置知识

**范数**：

- $L^\infty$：$\|f\|_\infty = \max_{[a,b]} |f(x)| = \|f(x)\|_{C[a,b]}$
- $L^1$：$\|f\|_1 = \int_a^b |f(x)| dx$
- $L^p$：$\|f\|_p = \left(\int_a^b |f(x)|^p dx\right)^{\frac{1}{p}}$

 $V$ 上实值函数 $x, y \in V$：

- $\|x\| \ge 0$（$=0$ iff $x = 0$）
- $\|kx\| = |k|\|x\|$（$k \in \mathbb{R}$）
- $\|x+y\| \le \|x\| + \|y\|$

$\|\cdot\|$ 为 $V$ 上范数，$(V, \|\cdot\|)$ 为赋范线性空间。

$V: \mathbb{R}$ 上向量空间，$\langle \cdot, \cdot \rangle: V \times V \to \mathbb{R}$：

- $\langle x, x \rangle \ge 0$（$=0$ iff $x=0$）
- $\langle \alpha x + \beta y, z \rangle = \alpha\langle x, z\rangle + \beta\langle y, z\rangle$
- $\langle x, y \rangle = \langle y, x \rangle$

$\langle \cdot, \cdot \rangle$：$V$ 上内积，$V$：内积空间。

**性质**：设 $V$ 是一个内积空间，$x \in V$，则 $\rho(x) = \sqrt{\langle x, x \rangle}$ 是 $V$ 上的一个范数，称其为内积诱导出的范数。反之如果范数 $\|\cdot\|$ 满足平行四边形法则：

$$\|x + y\|^2 + \|x - y\|^2 = 2(\|x\|^2 + \|y\|^2), \quad \forall x, y \in V,$$

则下面的公式也定义了一个内积：对于任意的 $x, y \in V$，

$$\langle x, y \rangle = \frac{1}{2}(\|x + y\|^2 - \|x\|^2 - \|y\|^2).$$

### 正交多项式

给定权函数 $w(x)$（非负，可积，有限零点，$(a,b)$ 上），$\forall f, g \in P_n$。

**带权内积**：

$$\langle f, g \rangle_w := \int_a^b w(x) f(x) g(x) dx$$

**带权 $L_w^2$ 范数**：

$$\|f\|_{L_w^2} = \sqrt{\langle f, f \rangle_w} = \sqrt{\int_a^b w(x) f(x)^2 dx}$$

注：$\forall g(x) \ge 0$（连续），$\text{if } \int_a^b w(x) g(x) dx = 0$ then $g(x) \equiv 0, x \in [a,b]$。

$w(x)$ 取：$1$，$\frac{1}{\sqrt{1-x^2}}$，$(1+x)^\alpha (1-x)^\beta$。

正交：$\langle f, g \rangle_w = 0$。

如何化为正交？$\{V_i\}_{i=1}^n$。

**Gram-Schmidt 正交化**：

$$\phi_1 = V_1$$

$$\phi_2 = V_2 - \frac{\langle V_2, \phi_1 \rangle}{\langle \phi_1, \phi_1 \rangle} \phi_1$$

$$\vdots$$

$$\phi_s = V_s - \sum_{i=1}^{s-1} \frac{\langle V_s, \phi_i \rangle}{\langle \phi_i, \phi_i \rangle} \phi_i, \quad s = 2, 3, \cdots, n$$

$\implies \langle \phi_i, \phi_j \rangle = 0$（$i \neq j$），$\text{Span}\{\phi_1, \cdots, \phi_s\} = \text{Span}\{V_1, \cdots, V_s\}$。

### 正交多项式性质

$\{1, x, \cdots, x^n\}$ $\xrightarrow{\text{G-S 正交化}}$ $\{p_i(x)\}_{i=0}^n$。

1. $p_n(x)$ 首项系数为 $1$，$\text{span}\{p_0, \cdots, p_n\} = \mathbb{P}_n$，$\langle p_n, q_{n-1} \rangle = 0$，$q_{n-1}$：不超 $n-1$ 次多项式。
2. 取 $p_{-1}(x) = 0$，$p_0(x) = 1$，对 $i \ge 0$ 有 $p_{i+1}(x) = (x - \alpha_i) p_i(x) - \beta_i p_{i-1}(x)$。

$$\alpha_i = \frac{\langle x p_i, p_i \rangle_w}{\langle p_i, p_i \rangle_w}, \quad \beta_i = \frac{\langle p_i, p_i \rangle_w}{\langle p_{i-1}, p_{i-1} \rangle_w}$$

3. $p_n(x)$ 在 $(a,b)$ 内有 $n$ 个互异实根，且 $p_n(x)$ 与 $p_{n+1}(x)$ 根交替排列。

> **证明**：
>
> 1. 由 Gram-Schmidt 正交化过程可知。
>
> $p_n = x^n - \sum_{i=1}^{n-1} \frac{\langle x^n, p_i \rangle_w}{\langle p_i, p_i \rangle_w} p_i$，$p_n(x)$ 首项系数为 $1$。
>
> $\langle p_i, p_j \rangle = \langle x^i - \sum_{k=1}^{n-1} \frac{\langle x^i, p_k \rangle_w}{\langle p_k, p_k \rangle_w} p_k, x^j - \sum_{k=1}^{n-1} \frac{\langle x^j, p_k \rangle_w}{\langle p_k, p_k \rangle_w} p_k \rangle = 0$（拆开乘）（$i \neq j$）。
>
> 取 $\sum_{i=0}^n a_i p_i = 0$，则 $\langle \sum_{i=0}^n a_i p_i, p_j \rangle_w = a_j \langle p_j, p_j \rangle_w = 0$，$a_j = 0$（$j = 0, \cdots, n$）。
>
> 故 $\text{span}\{p_0, \cdots, p_n\} = \mathbb{P}_n$。
>
> 同时 $\langle p_n, q_{n-1} \rangle = 0$（$q_{n-1}$：不超 $n-1$ 次多项式）成立。
>
> 2. 记 $x p_i(x) = \sum_{k=0}^{i+1} b_k p_k(x)$，且由1.知 $b_{i+1} = 1$。则 $\langle x p_i, p_j \rangle_w = b_j \langle p_j, p_j \rangle_w$。
>
> 则 $b_j = \frac{\langle x p_i, p_j \rangle_w}{\langle p_j, p_j \rangle_w}$，$j = 0, \cdots, i-2$ 时 $\langle x p_i, p_j \rangle_w = \langle p_i, x p_j \rangle_w = 0$。
>
> 即 $x p_i(x) = b_{i-1} p_{i-1}(x) + b_i p_i(x) + p_{i+1}(x)$。
>
> $j = i-1$ 时，$x p_{i-1} = \sum_{k=0}^{i-1} b_k' p_k + p_i = b_{i-2}' p_{i-2}(x) + b_{i-1}' p_{i-1}(x) + p_i(x)$。
>
> $\langle x p_i, p_{i-1} \rangle_w = b_{i-1} \langle p_{i-1}(x), p_{i-1}(x) \rangle_w = \langle p_i, x p_{i-1} \rangle_w = \langle p_i, p_i \rangle_w$。
>
> 故 $b_{i-1} = \frac{\langle p_i, p_i \rangle_w}{\langle p_{i-1}, p_{i-1} \rangle_w}$，记 $\beta_i = b_{i-1}$。
>
> $j = i$ 时，$b_i = \frac{\langle x p_i, p_i \rangle_w}{\langle p_i, p_i \rangle_w}$，记 $\alpha_i = b_i$。
>
> $$\implies p_{i+1}(x) = (x - b_i) p_i(x) - b_{i-1} p_{i-1}(x)$$
>
> 3. $\langle p_n, p_0 \rangle_w = \int_a^b w(x) p_n(x) \cdot p_0(x) dx = \int_a^b w(x) p_n(x) dx = 0$，$p_n(x)$ 至少有一个实根。
>
> 设 $p_n(x)$ 在 $(a,b)$ 上有 $k$ 个实根，有 $p_n(x) = (x - x_1)\cdots(x - x_k) g_{n-k}(x)$。
>
> $g_{n-k}(x)$ 在 $(a,b)$ 上不变号。若 $k < n$，有 $p_n \perp (x-x_1)\cdots(x-x_k) \in \mathbb{P}_k$，
>
> 即 $\int_a^b w(x) (x-x_1)^2 \cdots (x-x_k)^2 g_{n-k}(x) dx = 0$，则 $w(x) g_{n-k}(x) \equiv 0$，矛盾。故 $k = n$。
>
> 下证 $x_i \neq x_j$（$i \neq j$）：不妨设 $p_n = (x-x_1)^2 (x-x_3)\cdots(x-x_n)$，而 $p_n \perp (x-x_3)\cdots(x-x_n) \in \mathbb{P}_{n-2}$。
>
> $\int_a^b w(x) (x-x_1)^2 (x-x_3)^2 \cdots (x-x_n)^2 dx = 0$，矛盾（$w(x) > 0$）。故 $x_i \neq x_j$（$i \neq j$）。
>
> 4. 根相间性质：$[P_2, P_1]$，$P_1$ 根：$x_{1,1}$，$P_2$ 根 $x_{2,1} < x_{2,2}$。下证 $x_{2,1} < x_{1,1} < x_{2,2}$。
>
> 由三递推公式：$P_2(x) = (x - \frac{\langle x P_1, P_1 \rangle_w}{\langle P_1, P_1 \rangle_w}) \cdot P_1(x) - \frac{\langle P_1, P_1 \rangle_w}{\langle P_0, P_0 \rangle_w} \cdot P_0(x)$。
>
> 不妨设 $P_1$ 在 $a, x_{1,1}, b$ 处：$P_2(x_{1,1}) = -\beta_1 < 0$，而 $P_2(b) > 0$（二次式，在 $[a,b]$ 上有两个互异根）。
>
> 则 $x_{2,1} < x_{1,1} < x_{2,2}$，$x_{1,1} < x_{2,2} < b$。
>
> $[P_3, P_2]$ 类似地，需证明 $x_{3,1} < x_{2,1} < x_{3,2} < x_{2,2} < x_{3,3}$，$x_{3,1}, x_{3,2}, x_{3,3}$ 为 $P_3$ 根。
>
> 由三递推公式：$\beta_3(2,1) = -\beta_2 P_1(x_{2,1}) > 0$，$\beta_3(x_{2,2}) = -\beta_2 P_1(x_{2,2}) < 0$，而 $x_{2,1} < x_{2,2}$。
>
> 由数学归纳法即可证得。

### 常用的正交多项式

**Legendre 多项式**：$[-1,1]$，$w(x) = 1$。

$$L_k = \frac{1}{2^k} \sum_{j=0}^{[k/2]} (-1)^j C_k^j C_{2k-2j}^k x^{k-2j} = \frac{1}{2^k k!} \frac{d^k (x^2-1)^k}{dx^k}$$

其中 $C_k^j$ 表示组合数。Legendre 多项式对应的三递推公式为：

$$L_{k+1} = \frac{2k+1}{k+1} x L_k - \frac{k}{k+1} L_{k-1}, \quad L_0 = 1, L_1 = x.$$

Legendre 多项式的内积为 $\langle L_k, L_m \rangle_w = \delta_{km} \frac{2}{2k+1}$，其中 $\delta_{km}$ 为 Kronecker 记号，当 $k=m$ 时为 $1$，否则为 $0$。另外从 Legendre 多项式的定义可以看出其首项系数为 $\frac{1}{2^n} C_{2n}^n$。

**Chebyshev 多项式**：$T_k(x) = \cos(k \cdot \arccos x)$，$[-1,1]$，$w(x) = \frac{1}{\sqrt{1-x^2}}$。

三递推公式：$T_{k+1} = 2x T_k - T_{k-1}$（$T_0 = 1, T_1 = x$）。

Chebyshev 多项式的首项系数为 $2^{n-1}$，且有如下内积公式：

$$\langle T_n, T_n \rangle_\omega = \begin{cases} \pi/2, & n \neq 0, \\ \pi, & n = 0. \end{cases}$$

在 Chebyshev 多项式中，注意到 $\|T_n\|_{C[-1,1]} = 1$，且满足 $\|2^{1-n} T_n\|_{C[-1,1]} = \min_{p \in P_n^1} \|p\|_{C[-1,1]}$，其中 $P_n^1$ 为首一多项式。最后这个性质是最佳一致逼近多项式的充分必要条件（下一节的简单推论）。

**Laguerre 多项式**：当区间选为 $[0, +\infty)$，权函数 $\rho(x) = e^{-x}$ 时，所得到的正交多项式称为 Laguerre 多项式：

$$L_k(x) = \frac{e^x}{k!} \frac{d^k}{dx^k}(e^{-x} x^k).$$

Laguerre 多项式的正交性如下：

$$\int_0^\infty e^{-x} L_i(x) L_j(x) dx = \delta_{i,j}.$$

Laguerre 多项式满足三项递推公式如下：

$$L_{k+1}(x) = \frac{2k+1-x}{k+1} L_k(x) - \frac{k}{k+1} L_{k-1}(x), \quad L_0 = 1, L_1 = 1-x.$$

**Hermite 多项式**：当区间选为 $(-\infty, +\infty)$，权函数 $\rho(x) = e^{-x^2}$ 时，所得到的正交多项式称为 Hermite 多项式：

$$H_k(x) = (-1)^k e^{x^2} \frac{d^k}{dx^k} e^{-x^2}.$$

Hermite 多项式的正交性条件如下：

$$\int_{-\infty}^\infty e^{-x^2} H_i(x) H_j(x) dx = \delta_{i,j} 2^n n! \sqrt{\pi}.$$

Hermite 多项式的三项递推公式如下：

$$H_{k+1}(x) = 2x H_k(x) - 2k H_{k-1}(x), \quad H_0 = 1, H_1 = 2x.$$

## 最佳一致逼近

$$\text{dist}(f, p) = \|f - p\|_{C[a,b]} = \min_{p \in P_n} \max_{x \in [a,b]} |f(x) - p(x)|$$

**存在性**：对 $\forall f(x) \in C[a,b]$，$\exists\ p_n^* \in \mathbb{P}_n$，s.t. $\|f - p_n^*\|_{C[a,b]} = \inf_{p \in P_n} \|f - p\|_{C[a,b]}$。

> **证明**：最小偏差 $E_n^* = \inf_{p \in P_n} \|f - p\|_{C[a,b]}$，证明 $\exists\ p_n^* \in \mathbb{P}_n$，s.t. $\|f - p_n^*\|_{C[a,b]} = E_n^*$。
>
> 由 $E_n^*$ 定义可知，$\forall \varepsilon^k > 0^+$，$\exists\ g^k(x) \in \mathbb{P}_n$，s.t. $E_n^* \le \|f(x) - g^k(x)\|_{C[a,b]} \le E_n^* + \varepsilon^k$。
>
> 对于任意的 $g(x) = \sum_{i=0}^n c_i x^i$，我们可以定义 $\|g(x)\| = \sqrt{\sum c_i^2}$，即采用 $\{c_i\} \in \mathbb{R}^{n+1}$ 的欧几里得范数。不难验证上述定义给出了 $P_n$ 的一个新的向量范数，注意到 $P_n$ 是 $n+1$ 维的线性空间，其上的所有范数等价，即最大模范数等价于系数 $\{c_i\}$ 在 $\mathbb{R}^{n+1}$ 中的欧几里得范数。因此 $g^k$ 在无穷范数意义下是有界的序列，同时其单项式系数在欧几里得范数意义下也是有界的序列。
>
> 由此，根据 Bolzano-Weierstrass 定理，必然存在子列 $g_j^k(x)$ 使得其单项式系数都有极限。将这个极限多项式称为 $p_n^*$ 并再次利用范数的等价性，我们得到 $\|g_j^k - p_n^*\|_{C[a,b]} \to 0$。于是我们有：
>
> $$\|f - p_n^*\|_{C[a,b]} \le \|f - g_j^k\|_{C[a,b]} + \|g_j^k - p_n^*\|_{C[a,b]} \le E_n^* + \epsilon_j^k + \|g_j^k - p_n^*\|_{C[a,b]},$$
>
> 其中 $\epsilon_j^k \to 0$ 且 $\|g_j^k - p_n^*\|_\infty \to 0$。因此当 $j, k \to \infty$ 时，$\|f - p_n^*\|_\infty \to E_n^*$，定理得证。

### Chebyshev 震荡定理

由最优化问题刻画出最佳一致逼近多项式的充分必要条件。

$p_n^*$ 为最佳一致逼近多项式 $\Longleftrightarrow$ $f - p_n^*$ 存在至少 $n+2$ 个等高震荡最值点。

首先解释一下 $n+2$ 个高震荡最值点的数学定义，即如果 $g(x) \in C[a,b]$ 且 $\|g\|_{C[a,b]} = E$，则如果存在 $a \le x_0 < x_1 < \cdots < x_{n+1} \le b$ 使得 $g(x_i) = \pm (-1)^i E$，则称其为高震荡最值点组，公式最前面的 $\pm$ 表示第一个点是最大值点还是最小值点。

> **证明**：首先证明充分性（$\Leftarrow$）。使用反证法进行证明。不失一般性，设 $\{x_i\}_{i=0}^{n+1}$ 为 $f - p_n^*$ 的交错点组，且 $q \in \mathbb{P}_n$ 为最佳一致逼近多项式。假设 $p_n^*$ 不是最佳一致逼近，即存在 $q \in \mathbb{P}_n$ 使得 $\|f - q\|_{C[a,b]} < \|f - p_n^*\|_{C[a,b]}$。定义差函数 $g = p_n^* - q$，则有 $\|f - q\|_{C[a,b]} < \|f - p_n^*\|_{C[a,b]} = \|f - q - g\|_{C[a,b]}$，得 $\|g\|_{C[a,b]} > 0$。由于 $q \in \mathbb{P}_n$，则 $g \in \mathbb{P}_n$。
>
> 不妨设 $f(x_0) - p_n^*(x_0) = \|f - p_n^*\|_{C[a,b]}$，则 $f(x_i) - p_n^*(x_i) = (-1)^i \|f - p_n^*\|_{C[a,b]}$，从而：
>
> $$g(x_i) = p_n^*(x_i) - q(x_i) = f(x_i) - q(x_i) - (-1)^i \|f - p_n^*\|_{C[a,b]}.$$
>
> $i$ 是偶数：$g(x_i) = -\|f - p_n^*\|_{C[a,b]} - [q(x_i) - f(x_i)] \le \|f - q\|_{C[a,b]} - \|f - p_n^*\|_{C[a,b]} < 0$。
>
> $i$ 是奇数：$g(x_i) = \|f - p_n^*\|_{C[a,b]} + [q(x_i) - f(x_i)] \ge \|f - q\|_{C[a,b]} + \|f - p_n^*\|_{C[a,b]} > 0$。
>
> 从而 $\exists\ x_i^* \in (x_i, x_{i+1})$，使得 $g(x_i^*) = 0$，其中 $i = 0, \ldots, n$。因此 $g(x) = 0$ 产生矛盾，由此得证。
>
> 接下来证明必要性：（$\Rightarrow$）仍然使用反证法。定义误差函数：
>
> $$e(x) = f(x) - p_n^*(x), E = \|f - p_n^*\|_{C[a,b]}.$$
>
> 记 $\max_x e(x) = E_1, \min_x e(x) = -E_2$，若 $E_1 \neq E_2$，不妨令 $E = E_1 > E_2$，则我们可以构造 $p(x) = p_n^*(x) + \frac{1}{2}(E_1 - E_2)$，其满足：
>
> $$\max_x f(x) - p(x) = \frac{1}{2}(E_1 + E_2),$$
> $$\min_x f(x) - p(x) = -\frac{1}{2}(E_1 + E_2),$$
>
> 可以发现此时 $p(x)$ 是更好的逼近，和 $p_n^*$ 为最佳一致逼近矛盾，因此：
>
> 此时 $\|f - p(x)\|_{C[a,b]} = \frac{1}{2}|E_1 + E_2| < E_1$。
>
> $$\max_x f(x) - p_n^*(x) = E$$
>
> $$\min_x f(x) - p_n^*(x) = -E.$$
>
> 记：
>
> $$x_0 = \arg\min |x| \quad \text{s.t. } |e(x)| = E,$$
>
> $$x_1 = \arg\min(x), \quad \text{s.t. } x \ge x_0, e(x) = -e(x_0),$$
>
> $$\cdots$$
>
> $$x_i = \arg\min(x), \quad \text{s.t. } x \ge x_{i-1}, e(x) = -e(x_{i-1}).$$
>
> 可得 $x_0 < x_1 < \cdots < x_i$，满足交错点组的性质（等高震荡最值）。
>
> 不失一般性我们可以假设 $e(x_0) = -E$。下证 $i \ge n+1$。假设 $i \le n$，并且 $\{x: x \ge x_i, e(x) = -e(x_i)\} = \emptyset$。我们选取：
>
> $$y_i \in [x_{i-1}, x_i], \quad y_i = \arg\max y \quad \text{s.t. } e(y) = 0.$$
>
> 则可得 $x_0 < y_1 < x_1 < y_2 < x_2 < \cdots < y_i < x_i$。补充定义 $y_0 = a, y_{i+1} = b$，并且不妨：
>
> 则对 $\forall x \in [y_0, y_1], e(x)$ 都没有取到最大值 $E$。而 $\forall x \in [y_1, y_2], e(x)$ 都没有取到最小值 $-E$。依此思路，我们可以得到存在 $i+1$ 个正实数 $\epsilon_0, \ldots, \epsilon_i$ 满足：
>
> - 偶数项情形：$\forall x \in [y_{2k+2}, y_{2k+1}], e(x) \le E - \epsilon_{2k}$
> - 奇数项情形：$\forall x \in [y_{2k-1}, y_{2k}], e(x) \ge -E + \epsilon_{2k-1}$
>
> 定义 $\omega(x) = (y_1 - x)(y_2 - x)\cdots(y_i - x) \in \mathbb{P}_n$，只需选择 $p(x) = p^*(x) - t\omega(x) \in \mathbb{P}_n$，其中：
>
> $$t = \frac{\epsilon}{2\|\omega\|_{C[a,b]}}, \quad \epsilon = \min_{0 \le s \le i} \epsilon_s.$$
>
> 记 $f(x) - p(x)$ 为 $\tilde{e}(x)$，接下来说明 $p(x)$ 是一个更好的逼近函数。
>
> 首先考虑偶数项情形，由于：
>
> $\forall x \in [y_{2k+2}, y_{2k+1}], \quad e(x) \le E - \epsilon_{2k}$。
>
> 故：
>
> $\forall x \in [y_{2k+2}, y_{2k+1}], \quad \tilde{e}(x) \le E - \epsilon_{2k} + \frac{1}{2}\epsilon \le E - \frac{1}{2}\epsilon$。
>
> 对 $\forall x \in [y_{2k+2}, y_{2k+1}]$ 有：
>
> $$\tilde{e}(x) = e(x) + t \cdot (-1)^{2k} (x-y_1)\cdots(x-y_{2k})(y_{2k+1}-x)\cdots(y_i-x) > e(x) \ge -E,$$
>
> 而 $\tilde{e}(y_{2k}) = e(y_{2k}) = 0$，$\tilde{e}(y_{2k+1}) = e(y_{2k+1}) = 0$，从而 $\forall x \in [y_{2k}, y_{2k+1}]$ 有 $-E < \tilde{e}(x) < E$。
>
> 奇数项情形可以完全类似处理，最终我们发现 $\forall x \in [a,b]$，$-E < \tilde{e}(x) < E$。
>
> 综上所述，我们最终得到 $\|\tilde{e}\|_{C[a,b]} < E$，得到矛盾。故假设不成立，因此 $i \ge n+1$，即至少有 $n+2$ 个等高震荡最值点，定理得证。

> $p(x)$ 为更好的逼近。

### Chebyshev 震荡定理推论

 **推论** 4.2（Marcinkiewicz）对于任意连续函数，和任意正常数 $\epsilon$，存在一系列节点 $x_n$ 使得其插值多项式 $p_n$ 满足：$\|p_n - f\|_{C[a,b]} \le \epsilon$。

> **证明**：令 $E_n = \min_{p \in \mathbb{P}_n} \|f - \stackrel{*}{p_n}\|_{C[a,b]}$，且 $p_n^*$ 为最佳一致逼近多项式。根据 Weierstrass 第一逼近定理我们知道 $E_n \to 0$。下面我们说明 $p_n^*$ 一定是插值多项式。因为 $p_n^*$ 是最佳一致逼近，由 Chebyshev 震荡定理得到存在至少 $n+2$ 个等高震荡最值点。不难看出在任意两个相邻的等高震荡最值点之间一定存在一个零点，于是至少存在 $n+1$ 个点使得 $p_n^*(x)$ 和 $f(x)$ 取值相等，这就意味着 $p_n^*$ 一定是插值多项式，证毕。

> 逼近 ~ 插值。

紧接着我们来证明在所有的首一多项式中，具有最小范数的多项式必为 Chebyshev 多项式（相差一个常数倍）。

**推论**

令 $\mathcal{V} = \{p \in \mathbb{P}_n : p - x^n \in \mathbb{P}_{n-1}\}$，则我们有：

$$\frac{1}{2^{n-1}} T_n = \arg\min_{p \in \mathcal{V}} \|p\|_{C[-1,1]}.$$

> **证明**：我们考察如下的最佳一致逼近问题：多项式 $x^n$ 在空间 $\mathbb{P}_{n-1}$ 上的最佳一致逼近。令：
>
> $$p_{n-1}^* = \arg\min_{p \in \mathbb{P}_{n-1}} \|x^n - p\|_{C[-1,1]},$$
>
> 且 $r^*(x) = x^n - p_{n-1}^*$。由 Chebyshev 震荡定理知道 $r^*(x)$ 存在至少 $n+1$ 个等高震荡最值点是 $p_{n-1}^*$ 为最佳一致逼近的充分必要条件。从 Chebyshev 多项式的定义我们立刻发现 $\frac{1}{2^{n-1}} T_n$ 天然存在 $n+1$ 个等高震荡最值点，即：
>
> $$\frac{1}{2^{n-1}} T_n = r^*(x) = x^n - p_{n-1}^*.$$
>
> 于是对于任意的 $q(x) \in \mathcal{V}$，我们都有：
>
> $$\|q(x)\|_{C[-1,1]} = \|x^n - q_{n-1}(x)\|_{C[-1,1]} \ge \|x^n - p_{n-1}^*\|_{C[-1,1]} = \left\|\frac{1}{2^{n-1}} T_n\right\|_{C[-1,1]}.$$

### 最佳一致逼近是唯一的

> **证明**：设 $p_n(x), q_n(x)$ 均为最佳一致逼近多项式。记 $\|f - p_n\|_\infty = \|f - q_n\|_\infty = E_n$。
>
> 则取 $h_n = \frac{p_n + q_n}{2}$，则 $E_n \le \|f - \frac{p_n + q_n}{2}\| \le \frac{1}{2}\|f - p_n\| + \frac{1}{2}\|f - q_n\| = E_n$。
>
> 则 $e(x) = f(x) - h_n$ 有至少 $n+2$ 个等高震荡最值点。
>
> 不妨设 $f(x_i) - \frac{p_n(x_i) + q_n(x_i)}{2} = (-1)^i E_n$（新设的 $E_n$），$i = 0, \cdots, n+1$。
>
> $\Rightarrow [f(x_i) - p_n(x_i)] + [f(x_i) - q_n(x_i)] = 2(-1)^i E_n$。
>
> $\Rightarrow f(x_i) - p_n(x_i) = f(x_i) - q_n(x_i) = (-1)^i E_n$。
>
> 即 $p_n(x_i) = q_n(x_i) \implies p_n \equiv q_n$。$\square$

## Remez 算法

（$x_0, \cdots, x_{n+1}$ 等高震荡最值点）（一般难以在高维实现）

1. 初始化（Chebyshev 点）：$\{x_i\}_{i=0}^{n+1}$
2. 构造 $(p_n(x), E)$，s.t. $f(x_i) - p(x_i) = (-1)^i E$（$i = 0, \cdots, n+1$）
3. $e(x) = f(x) - p_n(x)$，找到 $e(x)$ 的 $n+2$ 个局部极值点（一般用牛顿法迭代几次）。在每个 $x_i$ 附近用一个局部极小（大）值点 $\hat{x}_i$ 代替 $x_i$。
4. 计算 $|f(\hat{x}_i) - p_n(\hat{x}_i)| = |e(x_i)|$，若 $\max |e(x_i)| - \min |e(x_i)| < \varepsilon$，停止迭代。

### Remez 算法第二步适定性

设 $f(x)$ 在 $[a,b]$ 上连续并且不为常数函数，令 $p_n(x)$ 表示次数不超过 $n$ 的多项式。对于任意给定的 $n+2$ 个交错点组 $\{x_i\}_{i=0}^{n+1}$，存在唯一的 $p_n(x)$ 和实数 $E$，满足 $f(x_i) - p_n(x_i) = (-1)^i E$。因此，Remez 算法的第二步总是可以找到一组满足要求的多项式 $p_n(x)$ 和实数 $E$。

> **证明**：我们可以通过构造两个插值多项式来证明此定理。首先令 $p_n^1(x)$ 为前 $n+1$ 个点的插值多项式满足 $p_n^1(x_i) = f(x_i)$，令 $p_n^2(x)$ 为在前 $n+1$ 个点取值为 $(-1)^i$ 的插值多项式，则我们可以将要求的多项式表示为：
>
> $$p_n(x) = p_n^1(x) - E p_n^2(x),$$
>
> 其中 $E$ 是一个实数。显然，$p_n(x)$ 满足条件 $f(x_i) - p_n(x_i) = (-1)^i E$，$i = 0, 1, \ldots, n$。将最后一个点的条件带入后，我们有：
>
> $$p_n^1(x_{n+1}) - p_n^2(x_{n+1}) E = f(x_{n+1}) + (-1)^n E$$
>
> $$p_n^1(x_{n+1}) - f(x_{n+1}) = E\left(p_n^2(x_{n+1}) + (-1)^n\right).$$
>
> 因此求解上述方程我们得到：
>
> $$E = \frac{p_n^1(x_{n+1}) - f(x_{n+1})}{p_n^2(x_{n+1}) + (-1)^n}.$$
>
> 最后我们需要解释 $E$ 的定义是有意义的，即分母非零。注意到 $p_n^2(x)$ 在区间 $(x_0, x_n)$ 中已经变号 $n$ 次，即 $p_n^2(x_{n+1})$ 和 $p_n^2(x_n)$ 同号，即 $|p_n^2(x_{n+1}) + (-1)^n| > 1$，这证明了 Remez 算法的第二步可行。
> $P_n \in \mathbb{P}_n$，最多 $n$ 次，最多 $n$ 个零点，已变号 $n$ 次，零点已在 $(x_0, x_n)$ 中全部取完。
> 若 $P_n \in \mathbb{P}_n$，而在 $n+1$ 个点取值相同 $\implies P_n \equiv \text{Cons}$。

### 代数意义

$n+2$ 个方程定 $n+2$ 个未知量

把 $f(x_i)-p_n(x_i)=(-1)^iE$ 展开：未知量是 $p_n$ 的 $n+1$ 个系数加 $E$，共 $n+2$ 个；方程也是 $n+2$ 个（$i=0,\dots,n+1$）。这是一个 $n+2$ 元的线性方程组，适定性即「系数矩阵非奇异」。

以 $n=0$（常值逼近）为例：两点 $x_0<x_1$，方程

$$f(x_0)-c=E,\qquad f(x_1)-c=-E.$$

相加消 $E$ 得 $c=\dfrac{f(x_0)+f(x_1)}{2}$，相减得 $E=\dfrac{f(x_1)-f(x_0)}{2}$——**常数最佳一致逼近就是两端点函数值的中点**，最小偏差等于两端差的一半。这正是例 5.4 中取 $f=x^2$、端点 $x=\pm1$ 时 $c=\frac{1+1}{2}=1$ 上方取半、$E=\frac12$ 的来历（对区间 $[0,1]$ 则得 $c=\frac12$）。

> 直觉：Remez 第二步就是「用 $n+2$ 个交错条件去解 $n+2$ 个未知数」的线性问题。适定性说明这一步总有解——算法不会卡住；剩下的第 3、4 步（找极值点、判断是否等幅）才是不动点迭代的部分。

## 接近最优逼近

假设插值点集 $X \subseteq [-1, 1]$，$p_n$ 是 $n$ 次插值多项式，$f \in C[a,b]$，则有：

$$\|f - p_n\|_\infty \le (\Lambda_n(X) + 1) E_n^*(f, X),$$

其中 $E_n^*(f, X)$ 为 $f$ 在插值点集 $X$ 上的 $n$ 次最佳逼近误差，$\Lambda_n(X)$ 为 Lebesgue 常数。

> **证明** $\{x_i\}_{i=0}^n$ 给定 $\implies$ 插值多项式 $P_n$。
>
> $$\|P_n - f\|_{C[a,b]} \le ?\ E_n.$$
>
> $$\Longleftrightarrow \begin{cases} p_n^* = \arg\min_{p \in P_n} \|f - p\|_{C[a,b]} \\ E_n^* = \|p_n^* - f\|_{C[a,b]} \end{cases}$$
>
> $$\le E_n.$$
>
> 而 $\|P_n - f\|_{C[a,b]} \le \|P_n - p_n^*\|_\infty + \|p_n^* - f\|_\infty \le (1 + \Lambda(X)) E_n$。
>
> $$\Lambda_n(X) = \sup \frac{\|P_n^{f - p_n^*}\|_{C[a,b]}}{\|f - p_n^*\|_{C[a,b]}}$$
>
> $$\|P_n - p_n^*\|_\infty \le \Lambda(X) \|f - p_n^*\|_\infty.$$
>
> $\{x_i\}_{i=0}^n$ 给定，$y_i \to P_n^{\{y_i\}}$，$\|P_r^{\{y_i\}}\|_\infty \le (\Lambda(X)) \|y_i\|_\infty$。

设 $f \in C[a,b]$，$p_n(x)$ 是 $n$ 次代数多项式，如果存在 $n+2$ 个点 $\{x_i\}_{i=0}^{n+1}$，使得 $p_n(x) - f(x)$ 在这些点上的符号变号，那么有 $\text{sgn}(f(x_i) - p_n(x_i)) = (-1)^i$：

$$\|f - p_n\|_\infty \le C E_n^*,$$

其中 $C = \frac{\|f-p_n\|_\infty}{\min_i |f(x_i)-p_n(x_i)|} \ge 1$，$E_n^*$ 为 $n$ 次最佳逼近误差。

> **证明**：证明思路主要是验证下面这个不等式：
>
> $$\min_i |f(x_i) - p_n(x_i)| \le E^*, _n$$
>
> 设一头为 +，$(-1)^n$。
>
> 首先记 $p_n(x) - f(x)$ 在 $x_0, x_1, \ldots, x_{n+1}$ 上的取值分别为 $-\lambda_0, \lambda_1, \ldots, (-1)^n \lambda_{n+1}$，其中 $\lambda_i > 0, i = 0, 1, \ldots, n+1$。接下来我们用反证法来验证，假设下式对任意 $i = 0, 1, \ldots, n+1$ 成立：
>
> $$\min_i \lambda_i > E_n^* = \|f - p_n^*\|_\infty, \quad \text{设 } E_n(x_i) = (-1)^i E_n^*$$
> $$= (p_n(x) - f(x)) + (f(x) - p_n^*)$$
>
> 其中 $p_n^*$ 表示 $n$ 次最佳一致逼近多项式。考虑 $h(x) := p_n(x) - p_n^*(x)$，有：
>
>
> 当 $i$ 为奇数时：$p_n(x_i) - p_n^*(x_i) \ge \lambda_i - E_n^* > 0$。
>
> 当 $i$ 为偶数时：$p_n(x_i) - p_n^*(x_i) \le -\lambda_i + E_n^* < 0$。
>
> 即 $h(x)$ 在点列 $\{x_i\}_{i=0}^n$ 上的取值依次变号，由中值定理可知 $h(x)$ 在 $(x_0, x_{n+1})$ 上至少有 $n+1$ 个零点，按照定义我们知道 $h(x)$ 是一个 $n$ 次多项式，矛盾产生。从而成立：
>
> $$\min_i \lambda_i \le E_n^*.$$

### 用接近最优判据卡住误差

设 $p_n$ 在 $n+2$ 个交错点上的误差幅度为 $\lambda_0,\dots,\lambda_{n+1}$，其最小值为 $\min_i\lambda_i$。由上面定理 $\min_i\lambda_i\le E_n^*$，于是

$$\|f-p_n\|_\infty \le C\,E_n^*,\qquad C=\frac{\|f-p_n\|_\infty}{\min_i\lambda_i}.$$

数值：若 $\|f-p_n\|_\infty=0.12$、交错点最小偏差 $\min_i\lambda_i=0.10$，则 $C=1.2$，反推 $E_n^*\ge\dfrac{0.12}{1.2}=0.10$，即最佳逼近误差至少 $0.10$——用手头这个插值多项式就卡住了最佳逼近的下界。

> 直觉：接近最优逼近给出一个实用判据——就算插值节点不是最佳节点，只要误差在选定的 $n+2$ 个点上「几乎等高」，插值多项式就离最佳逼近不远（差一个因子 $C$，越接近 $1$ 越好）。这把「求最佳」这个较难的问题，降成「用好节点做插值」这个易问题。

应用：正因如此，用 Chebyshev 节点做插值就能逼近 minimax 效果，代码里不必真跑 Remez，直接取 Chebyshev 节点即可（这也是 `chebfun` 类库的设计基础）。

## 最佳平方逼近

$$\text{dist}(f, p) = \int_a^b w(x) |f - p|^2 dx = \|f - p\|_{L_w^2}^2 \quad \text{（内积空间）}$$

**勾股定理**：

$$\|\sum c_i \phi_i\|_{L_w^2}^2 = \left\langle \sum_{i=0}^n c_i \phi_i, \sum_{j=0}^n c_j \phi_j \right\rangle = \sum_{i=0}^n c_i^2 \|\phi_i\|_{L_w^2}^2$$

在讨论最佳平方逼近之前，我们先回顾一下 Gibbs 现象：即间断函数的 Fourier 级数在间断点附近会出现震荡现象，并且无穷模误差在间断点附近不会随着 Fourier 级数次数的增加而减小。这种现象也被称为 Gibbs 现象，类似的多项式插值和逼近也存在 Gibbs 现象。

### 最佳平方逼近的存在唯一性

对于任意的 $f \in L_\omega^2$，存在唯一的最佳平方逼近元 $p_n^*$，且它可以表示为 $\{\phi_i\}_{i=0}^n$ 的线性组合 $p_n^* = \sum_{i=0}^n c_i \phi_i$，其中 $\{\phi_i\}_{i=0}^n$ 为 $\mathbb{P}_n$ 的一组基函数，系数 $c_i$ 是线性方程组 $Mc = f$ 的解，$M$ 是 $\{\phi_i\}_{i=0}^n$ 的 Gram 矩阵，即 $M_{ij} = \langle \phi_i, \phi_j \rangle_\omega, f_i = \langle f, \phi_i \rangle_\omega$。

> **证明**：取 $p_n = \sum_{i=0}^n C_i \phi_i$。
>
> $$\min_{p \in \mathbb{P}_n} \|f - p\|_{L_\rho^2}^2 \Longleftrightarrow \min_{\{C_i\}} \left\|f - \sum_{i=0}^n C_i \phi_i\right\|_{L_\rho^2}^2$$
>
> $$ \begin{aligned} \left\|f - \sum_{i=0}^n C_i \phi_i\right\|_{L_\rho^2}^2 &= \int_a^b \rho(x) \left|f(x) - \sum_{i=0}^n C_i \phi_i(x)\right|^2 dx \\ &= \int_a^b \rho(x) \left[f(x)^2 + \left(\sum_{i=0}^n C_i \phi_i(x)\right)^2 - 2f(x)\sum_{i=0}^n C_i \phi_i(x)\right] dx \\ &= \sum_{i=0}^n \sum_{j=0}^n C_i C_j \int_a^b \rho(x) \phi_i(x) \phi_j(x) dx - 2\sum_{i=0}^n C_i \int_a^b \rho(x) f(x) \phi_i(x) + \int_a^b \rho(x) f^2(x) dx \\ &= \sum_{i=0}^n \sum_{j=0}^n C_i C_j \langle \phi_i, \phi_j \rangle_\rho - 2\sum_{i=0}^n C_i \langle \phi_i, f \rangle_\rho + \langle f, f \rangle_\rho \\ &= C^T M c - 2 C^T f + \text{const}. \end{aligned} $$
>
> 求解：$\min C^T M c - 2 C^T f$。$M$ 已知对称，若为正定，则解：$Mc = f$。
>
> 正定？$\forall z \neq 0$，$z^T M z > 0$。
>
> $$z^T G z = \sum_{i=0}^n \sum_{j=0}^n z_i z_j \int_a^b \rho(x) \phi_i(x) \phi_j(x) dx$$
>
> $$= \int_a^b \rho(x) \left|\sum_{i=0}^n z_i \phi_i(x)\right|^2 dx > 0. \quad \square$$

### 例：连续最佳平方逼近

在 $[-1,1]$、$w=1$ 上，用 $\{1,x\}$ 对 $f(x)=x^2$ 作最佳平方逼近（$L^2$）。

取正交基 $\phi_0=p_0=1,\ \phi_1=p_1=x$（例 5.3）。按 $c_i=\dfrac{\langle f,\phi_i\rangle}{\langle\phi_i,\phi_i\rangle}$：

$$c_0=\frac{\langle x^2,1\rangle}{\langle1,1\rangle}=\frac{2/3}{2}=\frac13,\qquad c_1=\frac{\langle x^2,x\rangle}{\langle x,x\rangle}=\frac{0}{2/3}=0.$$

故最佳平方逼近为 $p^*(x)=\dfrac13$，与例 5.4 的最佳一致逼近 $b=\dfrac12$ **不同**（两者判据不同，答案一般不等）。

最小平方误差：

$$\|f-p^*\|_2^2=\int_{-1}^1\Big(x^2-\tfrac13\Big)^2dx=\int_{-1}^1\Big(x^4-\tfrac23x^2+\tfrac19\Big)dx=\frac25-\frac49+\frac29\approx0.1778.$$

> 直觉：$L^2$ 的最佳逼近系数就是「投影坐标」$\langle f,\phi_i\rangle/\langle\phi_i,\phi_i\rangle$，几何上等于把 $f$ 正交投影到子空间 $\text{span}\{\phi_i\}$——和向量投影一模一样，只是把点积换成积分。若基不正交，就得解 Gram 正规方程 $Mc=f$（数值上更麻烦），所以实践中总先正交化。

应用：最小二乘拟合、回归、压缩感知的重建都用 $L^2$ 投影；傅里叶级数就是取正交基 $\{\sin,\cos\}$ 的 $L^2$ 投影特例。
