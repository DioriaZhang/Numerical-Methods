# 非线性方程组求解

> [返回目录](00_目录.md)

- 非线性方程组解的存在性、唯一性等没有一般的理论。
- $\mathbb{R}^n$ 没有全序结构，导致所有使用了介值定理的算法在非线性方程组的情况都不再适用。
- 当 $n$ 比较大时，每一步迭代中如何快速求解是一个重要的问题。
- 一般情况下，寻求适合大范围初值的算法，或者多解问题的算法均非常困难。

## 不动点迭代

$F: \mathbb{R}^n \to \mathbb{R}^n$，$F(x) = 0 \implies G(x) = x$。

### 压缩映射原理

$D \subset \mathbb{R}^n$ 为非空闭集，$G: D \mapsto D$，有：

$$\|G(x) - G(y)\| \le \rho \|x - y\|, \quad \rho \in [0,1)$$

则 $\exists!\ x^* = G(x^*)$，且 $\forall\ x_0 \in D$，$x_{k+1} = G(x_k)$ 至少线性收敛到 $x^*$。

> 类似 n=1，和范数选取有关。

> **证明**：唯一性显然，下证存在性。
>
> 取 $\forall\ x_0 \in D$，记 $x_{k+1} = G(x_k)$。
>
> 由压缩映射，得：
>
> $$\|x_2 - x_1\| = \|G(x_1) - G(x_0)\| \le \rho \|x_1 - x_0\|$$
>
> $$\|x_3 - x_2\| = \|G(x_2) - G(x_1)\| \le \rho \|x_2 - x_1\| \le \rho^2 \|x_1 - x_0\|$$
>
> $$\vdots$$
>
> $$\|x_{n+1} - x_n\| \le \rho^n \|x_1 - x_0\|, \quad \forall m < n$$
>
> $$ \begin{aligned} \|x_n - x_m\| &\le \|x_n - x_{n-1}\| + \cdots + \|x_{m+1} - x_m\| \\ &\le \rho^{n-1} \|x_1 - x_0\| + \cdots + \rho^{m+1} \|x_1 - x_0\| + \rho^m \|x_1 - x_0\| \\ &\le \frac{\rho^m}{1-\rho} \|x_1 - x_0\| \end{aligned} $$
>
> 故得 $\{x_n\}$ 是 Cauchy 列，$\lim_{n \to \infty} x_n = x^* \in D$。
>
> 且 $G(x)$ 为 Lipschitz 连续。
>
> 故 $x^* = \lim_{n \to \infty} x_{n+1} = \lim_{n \to \infty} G(x_n) = G(\lim_{n \to \infty} x_n) = G(x^*)$。

##  牛顿法

$x_k \approx x^*$，$F(x^*) = 0$：

$$0 = F(x^*) \approx F(x_k) + \nabla F(x_k)(x^* - x_k)$$

$$x_{k+1} = x_k - [\nabla F(x_k)]^{-1} F(x_k)$$

 Frechét 导数（全微分，给出 $\nabla F(x_k)$）

$F: \mathbb{R}^n \to \mathbb{R}^n$，$G: D \to \mathbb{R}^{n \times n}$，$\forall x \in \text{int} D$，有：

$$\lim_{\|h\| \to 0} \frac{\|F(x+h) - F(x) - G(x) h\|}{\|h\|} = 0, \quad G = \nabla F$$

$$F(x + h) = F(x) + G(x) h + o(\|h\|) \quad (\|h\| \to 0)$$

> 不依赖 $\mathbb{R}^n$ 基底。

取 $\mathbb{R}^n$ 基底 $\{e_i\}$：

$$G(x) = \nabla F(x), \quad (\nabla F)_{ij} = \frac{\partial F_i}{\partial x_j} \quad \text{（Jacobi 矩阵）}$$

### 算法

$$ \begin{array}{l} \text{输入}\ x_0,\ \varepsilon > 0,\ k = 0 \\[2pt] \textbf{while}\ \textbf{True}\ \textbf{do} \\[2pt] \qquad \text{计算}\ x_{k+1} = x_k - J(x_k)^{-1} F(x_k),\quad k = k+1 \\[2pt] \qquad \textbf{if}\ \lvert F(x_k)\rvert < \varepsilon\ \textbf{: break} \\[2pt] \qquad \textbf{else}\ \textbf{: pass} \\[2pt] \qquad \text{计算}\ \lg \|x_{k+1} - x_k\|\ \text{（误差分析）} \\[2pt] \text{输出}\ x_k \end{array} $$

> 直觉：多维牛顿法把一维的「切线」换成「用 Jacobi 矩阵定义的切超平面」，每步解一个线性方程组 $J(x_k)\Delta x=-F(x_k)$。核心代价就是**每步要求解 $n\times n$ 线性方程组**（或等价地求 Jacobi 逆），当 $n$ 很大时这是瓶颈——这正是拟牛顿法和非精确牛顿法的出发点。

### 收敛性
#### 局部二次收敛

$F(x^*) = 0$，$\exists B(x^*, R)$，有：

1. $\|[\nabla F(x^*)]^{-1}\| \le C$
2. $\|\nabla F(x) - \nabla F(y)\| \le L \|x - y\|$（比二次可导稍弱）

则 $\exists\ r = \min\{R, \frac{1}{2CL}\}$ s.t. $x_0 \in B(x^*, r)$，有 $x_k \to x^*$，且：

$$\|x_{k+1} - x^*\| \le CL \|x_k - x^*\|^2$$

$$\Rightarrow x_{k+1} = x_k - [\nabla F(x_k)]^{-1} F(x_k)$$

>  Jacobi 矩阵求逆。

> **证明**：只需证明 $\|x_1 - x^*\| \le CL \|x_0 - x^*\|^2$，后面用数学归纳法便可证同。
>
> $$\nabla F(x_0)(x_1 - x_0) = -F(x_0)$$
>
> 左右同减 $x^*$：
>
> $$x_1 - x^* = -[\nabla F(x_0)]^{-1} (\nabla F(x_0)(x^* - x_0) + F(x_0))$$
>
> $$\|x_1 - x^*\| \le \|\nabla F(x_0)\|^{-1} \cdot \|F(x^*) - F(x_0) - \nabla F(x_0)(x^* - x_0)\|$$
>
> 1. 记 $A = I - [\nabla F(x^*)]^{-1} \nabla F(x_0) = [\nabla F(x^*)]^{-1} [\nabla F(x^*) - \nabla F(x_0)]$，则 $\nabla F(x_0) = \nabla F(x^*)(I - A)$，从而：
>
> $$[\nabla F(x_0)]^{-1} = (I - A)^{-1} [\nabla F(x^*)]^{-1}$$
>
> $$\le C \|\nabla F(x^*) - \nabla F(x_0)\|$$
>
> $$\le CL \|x^* - x_0\| \le \frac{1}{2}$$
>
> 故 $\|(I-A)^{-1}\| \le \frac{1}{1-\|A\|} \le 2$。
>
> 故 $\|[\nabla F(x_0)]^{-1}\| \le \|(I-A)^{-1}\| \cdot \|[\nabla F(x^*)]^{-1}\| \le 2C$。
>
> 2. $\|F(x^*) - F(x_0) - \nabla F(x_0)(x^* - x_0)\|$：
>
> 定义 $f(t) \triangleq F(x_0 + t e)$，其中 $e = \frac{x^* - x_0}{\|x^* - x_0\|}$。
>
> $t \in [0, \alpha]$，$\alpha = \|x^* - x_0\|$。
>
> 详细推导：
>
> $$\|F(x^*) - F(x_0) - \nabla F(x_0)(x^* - x_0)\|$$
>
> $$= \|F(x^*) - F(x_0) - \alpha \nabla F(x_0) e\|$$
>
> $$= \|f(\alpha) - f(0) - f'(0) \alpha\|$$
>
> $$= \left\|\int_0^\alpha f'(t) dt - f'(0) \int_0^\alpha dt\right\|$$
>
> $$= \left\|\int_0^\alpha (f'(t) - f'(0)) dt\right\|$$
>
> $$\le \int_0^\alpha \|f'(t) - f'(0)\| dt$$
>
> $$\le \int_0^\alpha \|\nabla F(x_0 + t e) - \nabla F(x_0)\| dt$$
>
> $$\le \int_0^\alpha L t\, dt = \frac{L}{2} \alpha^2 = \frac{L}{2} \|x^* - x_0\|^2$$
>
> $$\|x_1 - x^*\| \le CL \|x^* - x_0\|^2$$

#### 缺点和改进方向
**缺点**：计算代价略大（$n$ 巨大）。

$$0 = F(x^*) \approx F(x_k) + \nabla F(x_k)(x^* - x_k)$$

$$\nabla F(x_k)(x_{k+1} - x_k) = -F(x_k)$$

**改进方向：**

1. 非精确牛顿：

$$\|\nabla F(x_k) \Delta x_k + F(x_k)\| \le \eta_k \|F(x_k)\|$$

2. L-M 方法（Levenberg-Marquardt）：

$$\Delta x_k = \arg\min \|\nabla F(x_k) \Delta x + F(x_k)\|^2 + \alpha_k \|\Delta x+x_k\|^2$$

与「稳（近梯度下降）」之间切换——这正是它在非线性最小二乘里极其常用的原因。

## 拟牛顿法

#### 推导

目标：$F(x^*) = 0$。

Newton 法：$x_{k+1} = x_k - [\nabla F(x_k)]^{-1} F(x_k)$。

find $B_k \approx \nabla F(x_k)$，有：

$$B_k(x_k - x_{k-1}) = F(x_k) - F(x_{k-1})$$

令 $\Delta B = B_k - B_{k-1}$：

$$(\Delta B + B_{k-1})(x_k - x_{k-1}) = F(x_k) - F(x_{k-1})$$

$$\Delta B(x_k - x_{k-1}) = F(x_k) - F(x_{k-1}) - B_{k-1}(x_k - x_{k-1})$$

$$B_k = B_{k-1} + \Delta B, \quad \Delta B = \arg\min \|A\|_F^2, \quad Ax = b$$

**引理**：$A \in \mathbb{R}^{n \times n}$，$\min \|A\|_F^2$，$\exists!$ 解 $A = \frac{b x^T}{\|x\|_2^2}$（列、行向量）。

> **证明**：原问题等价于求解如下的优化问题：记 $A = [a_1, a_2, \cdots, a_n]^T$，
>
> $$\min \|A\|_F^2 = \sum_{i=1}^n \|a_i\|_2^2 \tag{2.8}$$
>
> $$\text{subject to } a_i^T x = b_i, \quad i = 1, 2, \cdots, n \tag{2.9}$$
>
> 很显然该问题可以被分解为 $n$ 个独立的子问题来求解：
>
> $$\min \|a_i\|_2^2 \tag{2.10}$$
>
> $$\text{subject to } a_i^T x = b_i \tag{2.11}$$
>
> 记 $x$ 张成的空间为 $U = \text{span}\{x\}$，其正交补空间为 $V$，令 $V$ 的一组标准正交基为 $\{x_1, x_2, \cdots, x_{n-1}\}$。于是任意的向量可以将其表示为 $a_i = \sum_{j=1}^{n-1} \lambda_j^i x_j + \mu \frac{x}{\|x\|_2^2}$。在这个表示下，约束 $a_i^T x = b_i$ 可以转化为 $a_i^T x = \mu \implies \mu = b_i$，并将 (2.10) 改写成：
>
> $$\min \sum_{j=1}^{n-1} (\lambda_j^i)^2 + \frac{\mu^2}{\|x\|_2^2} \tag{2.12}$$
>
> $$\text{subject to } \mu = b_i \tag{2.13}$$
>
> 显然其最优解为 $\lambda_j^i = 0, \forall j = 1, 2, \cdots, n-1, \forall i = 1, 2, \cdots, n$。于是 $a_i = b_i \frac{x}{\|x\|_2^2}, \forall i = 1, 2, \cdots, n$，即 $A = \frac{b x^T}{\|x\|_2^2}$。

### Sherman-Morrison 公式

$A$ 可逆且 $v^T A^{-1} u \neq -1$，则 $A + u v^T$ 可逆，且：

$$(A + u v^T)^{-1} = A^{-1} - \frac{A^{-1} u v^T A^{-1}}{1 + v^T A^{-1} u}$$

直接右乘 $A+uv^T$ 应得单位阵。记 $B = A^{-1} - \dfrac{A^{-1}uv^TA^{-1}}{1+v^TA^{-1}u}$，则

$$\begin{aligned}
B(A+uv^T) &= A^{-1}A + A^{-1}uv^T - \frac{A^{-1}uv^T A^{-1}A + A^{-1}uv^T A^{-1}uv^T}{1+v^TA^{-1}u}\\
&= I + A^{-1}uv^T - \frac{A^{-1}uv^T + A^{-1}u\,(v^TA^{-1}u)\,v^T}{1+v^TA^{-1}u}\\
&= I + A^{-1}uv^T - \frac{A^{-1}uv^T(1+v^TA^{-1}u)}{1+v^TA^{-1}u} = I.
\end{aligned}$$

> 直觉：Sherman-Morrison 说的是「秩一修正的逆 = 原逆 + 一个秩一修正」。它把「每步重算一次 $n^3$ 求逆」降成「$O(n^2)$ 更新」，正是拟牛顿法能在 $n$ 很大时还能用的关键。拟牛顿法里 $\Delta B$ 恰是秩一（或秩二）修正，于是 $H_k=B_k^{-1}$ 可增量维护而不必真求逆。

**一般情况**：

$A: n \times n$ 可逆，$U: n \times k$，$V: k \times n$，$k < n$。

$B = A + UV$，如 $I_k + V A^{-1} U$ 可逆，则 $B$ 可逆：

$$B^{-1} = A^{-1} - A^{-1} U (I_k + V A^{-1} U)^{-1} V A^{-1}$$

### BFGS 迭代

初始：$B_0, x_0, x_1$。

$$B_k = B_{k-1} + \frac{b x^T}{\|x\|_2^2}$$

$$b = F(x_k) - F(x_{k-1}) - B_{k-1}(x_k - x_{k-1})$$

$$x = x_k - x_{k-1}$$

$$x_{k+1} = x_k - B_k^{-1} F(x_k)$$

简化计算：$B_k^{-1} = H_k$。

记 $s_k = x_{k+1} - x_k$，$y_k = F(x_{k+1}) - F(x_k)$。

$$B_{k+1} s_k = y_k, \quad B_{k+1} = B_k + u_k s_k^T$$

$$u_k = \frac{y_k - B_k s_k}{s_k^T s_k}, \quad B_{k+1} = B_k + \frac{(y_k - B_k s_k) s_k^T}{s_k^T s_k}$$

故：

$$B_{k+1}^{-1} = B_k^{-1} - \frac{B_k^{-1} u_k s_k^T B_k^{-1}}{1 + s_k^T B_k^{-1} u_k}$$

$$H_{k+1} = H_k - \frac{(H_k y_k - s_k) s_k^T H_k}{s_k^T H_k y_k}$$

### 拟牛顿法步骤

1. 给定 $x_0, H_0, \varepsilon > 0$，$k := 0$（$H_0$ 一般取 $I$）

2. 停机准则

3. $x_1 = x_0 - H_0 F(x_0)$（算法）：

$$s_k = x_{k+1} - x_k = -H_k F(x_k)$$

$$y_k = F(x_{k+1}) - F(x_k)$$

$$H_{k+1} = H_k - \frac{(H_k y_k - s_k) s_k^T H_k}{s_k^T H_k y_k}$$

$$x_{k+2} = x_{k+1} - H_{k+1} F(x_{k+1})$$

> 直觉：拟牛顿法用「割线条件」$B_k(x_k-x_{k-1})=F(x_k)-F(x_{k-1})$ 来**近似** Jacobi，绕开昂贵的精确求导与求逆。它拿上一步「实际走的方向」与「函数实际变化」比对，反推一个近似导数，再用 Sherman-Morrison 增量更新逆矩阵。代价是收敛从二阶降到超线性，但每步便宜得多——这就是它的性价比。

## 拓展

**逆牛顿法**：

$H_k \sim D^{-1} F(x_k)$，$x_{k+1} = x_k - H_k F(x_k)$。

$$H_k(F(x_k) - F(x_{k-1})) = x_k - x_{k-1}$$

$$H_k \sim H_{k-1}$$

**同伦法**：

为解 $F(x) = 0$。

L-族函数：$(1-\lambda) G(x) + \lambda F(x) \triangleq H(x; \lambda)$，$0 = \lambda_1 < \cdots < \lambda_n = 1$。

用 Newton 迭代解零点：$x(\lambda_{k+1}) \to H(x, \lambda_k) \to x(\lambda_k) \to H(x, \lambda_{k+1})$。

例：优化：$\min f(x) : f(x) + \lambda Q(x) \frac{1}{2} \|x\|^2$。
